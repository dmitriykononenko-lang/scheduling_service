# Продуктовые решения

Источник правды по решениям, ранее открытым в ТЗ §11. Обновляется по мере уточнений.

## Решения §11

| # | Вопрос | Решение | Комментарий |
|---|---|---|---|
| 11.1 | Название / домен | **Созвон** | Домены-кандидаты `sozvon.ru` / `sozvon.app` — проверить занятость и зарегистрировать. Имя точно в нишу (созвоны/консультации) |
| 11.2 | Первый эквайер | **ЮKassa + Т-Банк (оба)** | Подключаем обоих с MVP для широкого охвата; нужна абстракция провайдера платежей |
| 11.3 | Монетизация оплат | **Подписка + комиссия с оборота** | Комиссия ~1–3% сверх эквайринга (стратегия §12 — заходить через платёжный оборот) |
| 11.4 | Видеосервисы MVP | **Яндекс.Телемост + Google Meet + Zoom** | Телемост — без VPN-рисков; Meet — через Google Calendar; Zoom — отдельный OAuth |
| 11.5 | Тарифы | **Pro 490–690 ₽/мес** (год −20%), **Free «мягкий»** | Free: безлимит встреч + брендинг сервиса; оплаты/API/интеграции — только на Pro |
| 11.6 | Запуск | **Закрытая бета** | 10–30 организаторов, отладка оплаты/синхронизации; затем self-service |

## Следствия для архитектуры (TODO будущих срезов — здесь не реализуются)

- **Оплата (§4.7):** абстракция `PaymentProvider` с двумя реализациями — ЮKassa и Т-Банк.
  Идемпотентность и аудит уже заложены: `Payment.idempotency_key`, `Payment.provider`,
  `Payment.raw_payload`, уникальность `(provider, external_id)`. Бронь с предоплатой создаётся в
  `pending_payment`, подтверждается по вебхуку `payment.succeeded`; неоплаченные освобождает
  Celery-задача `release_expired_unpaid_bookings` (сейчас заглушка).
- **Монетизация (комиссия):** при оплате брони удерживать комиссию платформы. Вероятна будущая
  колонка `Payment.platform_fee`. Подписка Pro — через тот же эквайер.
- **Тарифы:** в `Subscription` уже есть `plan`/`status`/`trial_ends_at`. Позже — проверки лимитов
  «мягкого Free»: приём оплат, публичный API/webhooks и внешние интеграции доступны только при
  `plan == pro`; снятие брендинга сервиса — на Pro.
- **Закрытая бета:** гейтинг регистрации (инвайт-коды или allowlist email) — небольшой срез
  поверх `services/auth.py` и `User`. До запуска self-service регистрация закрыта/по инвайту.
- **Видео (§4.8):** провайдеры видео-ссылок — Телемост, Google Meet (conferenceData),
  Zoom (OAuth). Поле `Booking.location_url` уже есть.

## Открытые уточнения (не блокируют MVP)
- Точная ставка комиссии с оборота (1% / 2% / 3%) и её отображение в оферте.
- Регистрация и DNS домена `sozvon.*`.
- Годовая цена Pro (ориентир −20% от месячной × 12).
